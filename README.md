# LOYALLOOP — Customer Loyalty & Rewards Program Platform (SaaS)

> **"Turn Every Purchase Into Loyalty."**
> A modern retail-tech & customer engagement SaaS platform website template.

---

## 🚀 Overview

**LOYALLOOP** is a complete, production-quality, commercial-grade SaaS marketing website template built for customer loyalty programs, digital wallet passes, VIP membership tiers, and automated customer retention.

Built specifically for marketplaces like ThemeForest, TemplateMonster, Creative Market, and direct enterprise software client projects.

---

## 🌟 Key Features

- **2 Distinct Homepage Layouts:**
  - `index.html`: High-conversion SaaS marketing landing page with interactive customer journey flowchart.
  - `home-2.html`: Editorial retail-tech showcase centered around the **Loyalty Loop™** circular retention framework.
- **Complete Solutions Suite:**
  - Retail Loyalty (`retail-loyalty.html`)
  - Restaurant Loyalty (`restaurant-loyalty.html`)
  - Ecommerce DTC Loyalty (`ecommerce-loyalty.html`)
  - Tiered Membership Programs (`membership-programs.html`)
  - Customer Rewards & Catalogs (`customer-rewards.html`)
  - Automated Retention & Win-Backs (`retention-programs.html`)
  - Solutions Overview (`solutions.html`)
- **Comprehensive Feature Breakdown:**
  - Feature archive (`features.html`)
  - Detailed feature deep-dive (`feature-details.html`)
- **Commercial SaaS Pricing:**
  - Monthly vs Annual toggle with 20% savings badge (`pricing.html`)
  - Full feature comparison table
  - Categorized pricing FAQ accordion
  - Interactive ROI & Points Calculator
- **Fictional Case Study Archive:**
  - Real-world modeled stories with category filtering (`case-studies.html`)
  - Deep-dive case study analysis with strategy and outcomes (`case-study-details.html`)
- **Resource Center & Education:**
  - Knowledge hub (`resources.html`)
  - 10-Chapter strategic guide: *"What Makes a Customer Loyalty Program Work?"* (`loyalty-guide.html`)
  - Searchable FAQ center (`faqs.html`)
  - Blog archive with search, filter tabs, and pagination (`blog.html`)
  - Long-form blog article template with author profile & related posts (`blog-details.html`)
- **Standalone Front-End Auth & Demo Pages (No Dashboard/Cart):**
  - Standalone Login demo (`login.html`)
  - Standalone Signup demo with live password strength meter (`signup.html`)
  - Password reset demo (`forgot-password.html`)
  - Contact sales form with instant validation feedback (`contact.html`)
  - Branded 404 page (`404.html`)
  - Pre-launch coming soon page with live countdown timer (`coming-soon.html`)
- **Theme & UX Engine:**
  - Light / Dark mode toggle with system preference detection and `localStorage` persistence.
  - GSAP micro-animations with strict `prefers-reduced-motion` accessibility support.
  - Back-to-top button with smooth scroll.
  - 100% responsive across all viewport sizes (from 320px to 2560px+).

## 🛠️ Technology Stack

- **HTML5:** Semantic, accessible markup.
- **Bootstrap 5.3.3:** Responsive layout grid and components.
- **CSS3:** Custom properties/tokens, gradients, glassmorphism accents, and responsive typography (`clamp()`).
- **Vanilla JavaScript (ES6+):** Light/dark theme toggle, localStorage persistence, live ROI calculator, form validation, filter tabs, password visibility, and countdown clock.
- **GSAP 3.12.5:** Micro-animations with reduced-motion accessibility checks.
- **Bootstrap Icons 1.11.3:** Complete vector icon set with offline font fallback.
