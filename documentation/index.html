CHAPTER 01

Introduction & Overview

LOYALLOOP is a premium, modern, commercial-grade Customer Loyalty & Rewards Program Platform (SaaS) website template designed specifically for ThemeForest, TemplateMonster, Creative Market, and client software projects.

Engineered with HTML5, Bootstrap 5.3+, Vanilla CSS3 custom properties, and Vanilla JavaScript with GSAP micro-animations. It represents a state-of-the-art retail-tech and customer retention SaaS brand with 2 homepage variations, complete industry solutions, detailed feature breakdowns, interactive ROI calculators, categorized pricing, full resource hubs, and front-end authentication demos.

CHAPTER 03

Design Tokens & CSS Variables

All color tokens, surface elevations, border radii, and shadows are defined as CSS custom properties in assets/css/style.css. 

:root {
  --primary: #4F46E5;            /* Royal Indigo */
  --accent: #10B981;             /* Emerald Mint */
  --reward-gold: #F59E0B;        /* Amber Gold */
  --bg-body: #F8FAFC;            /* Light Mode Background */
  --bg-surface: #FFFFFF;         /* Card Surface */
  --text-main: #0F172A;          /* Charcoal Slate */
  --text-muted: #64748B;
  --border-color: #E2E8F0;
  --font-heading: 'Plus Jakarta Sans', sans-serif;
  --font-body: 'Inter', sans-serif;
  --font-mono: 'Space Grotesk', sans-serif;
}
CHAPTER 04

Light / Dark Theme System

The template features an instant, flicker-free Light / Dark mode engine. The user's preference is detected via OS system settings (prefers-color-scheme) and persisted in browser localStorage under the key loyalloop-theme-preference. 

// Activating Dark Mode dynamically via HTML attribute:
<html lang="en" data-theme="dark">
CHAPTER 05

Interactive Components

  • Pricing Toggle: Switch between Monthly and Annual billing with instant price multipliers and 20% discount badges.
  • ROI & Points Calculator: Dual range sliders estimating monthly incremental retention revenue and points generated.
  • Category Filter Buttons: Seamlessly filter Case Studies and Blog archives without page reloads.
  • Live Countdown Timer: Configurable countdown clock on coming-soon.html.
  • Password Strength Meter: Live password scoring on signup.html.
